Landing Page Scorecard

Use this quick scorecard before buying traffic, redesigning the page, or asking for feedback. It helps you separate copy clarity from design taste.

Start scoringUse teardown checklist

Score each item from 0 to 2.

0 = missing or unclear · 1 = partly there · 2 = clear enough for a stranger. A simple page with 18+ points is usually ready to test; below 12, fix the message before changing visuals.

Hero

1. Audience clarity

Can a stranger tell who the offer is for within 5 seconds?

Score: 0 / 1 / 2

Hero

2. Outcome clarity

Does the headline promise a specific useful outcome instead of naming only a category?

Score: 0 / 1 / 2

CTA

3. Next step

Is there one primary action, and does the visitor know what happens after clicking?

Score: 0 / 1 / 2

Offer

4. Deliverables

Does the page say what is included, what is not included, and the expected timeline or process?

Score: 0 / 1 / 2

Proof

5. Trust evidence

Is there proof: examples, screenshots, before/after process, testimonials, credentials, or a public sample?

Score: 0 / 1 / 2

Friction

6. Objections

Does the FAQ answer price, fit, timing, guarantee/no-guarantee, and required inputs?

Score: 0 / 1 / 2

Lead magnet

7. Low-friction option

If the visitor is not ready to buy, is there a useful checklist, worksheet, example, or brief template?

Score: 0 / 1 / 2

Message match

8. Source alignment

Does the landing page match the promise made in the ad, post, email, referral, or profile link?

Score: 0 / 1 / 2

Scope

9. Fit filter

Does the page make it clear who is a good fit and who should not buy/request this?

Score: 0 / 1 / 2

Final CTA

10. Repeated action

After the proof and FAQ, is the call to action repeated with the same wording or intent?

Score: 0 / 1 / 2

How to read the score

Fix the lowest-scoring section first.

Do not redesign everything at once. If hero clarity scores low, rewrite the headline before changing layout. If proof scores low, add a concrete example before adding more claims.

Suggested actions

  • 0–11: clarify audience, outcome, CTA, and offer boundaries.
  • 12–17: add proof, FAQ, and a lower-friction resource.
  • 18–20: publish, share with a small audience, and learn from replies.
