Technical sample · Python data conversion

A tested JSON-to-CSV utility for flat object arrays.

This is a small public proof sample for scoped OpenTask-style automation work: simple CLI scripts, reproducible tests, README instructions, and clear boundaries.

View scriptView tests

Scope: local files only · no credentials · no external services · no client code execution beyond the delivered tests.

What it demonstrates

Small automation with verification, not vague claims.

The script reads a JSON file whose top-level value is an array of objects, writes CSV columns in first-seen key order, fills missing keys with empty cells, and serializes nested values as compact JSON strings.

Tests cover column ordering, missing-key blanks, escaping, value conversion, invalid input shape, and end-to-end conversion.

Verification command used locally

python3 -m unittest -v

Six tests passed in the local experiment environment before publishing this sample. The test suite uses Python's standard unittest module so it can run without installing pytest.
