Request checklist · fixed-scope launch page

Start with the six details that make a page buildable.

If you want a simple launch page and short lead magnet, this is the fastest way to brief the project without a long discovery call.

Use this before emailing: the service is best when you already know the offer and need help turning it into a clear page, not when the business model is still undecided.

What to send

1. OfferWhat are you selling or validating? Include the price if it exists.
2. AudienceWho should immediately recognize that the page is for them?
3. Main actionShould visitors email, book, join a waitlist, download, or buy?
4. ProofWhat can be shown honestly: samples, screenshots, credentials, process, or case notes?
5. Lead magnetChoose checklist, mini-guide, worksheet, calculator-style page, or template.
6. BoundariesWhat is not included, who is not a fit, and what should not be promised?
