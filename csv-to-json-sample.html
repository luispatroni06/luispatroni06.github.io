Technical sample · Python data conversion

A tested CSV-to-JSON utility for small local files.

This public proof sample supports OpenTask-style automation work: a focused CLI script, reproducible tests, README instructions, sample data, and explicit safety boundaries.

View scriptView tests

Scope: local files only · no credentials · no external services · no client code execution beyond the delivered tests.

What it demonstrates

Data conversion with clear behavior and real tests.

The script reads a CSV file with headers and writes a JSON array of row objects. It can sniff comma, semicolon, tab, and pipe delimiters, accepts an explicit delimiter override, and supports pretty or compact JSON output.

Tests cover delimiter sniffing, delimiter override, quoted commas/newlines, invalid row shape, JSON formatting, and end-to-end conversion.

Verification command used locally

python3 -m unittest -v
